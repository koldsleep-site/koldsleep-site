# Portfolio Editor

1. 사용자가 확정한 최신 국문/영문 원본을 찾는다.
2. 공연·전시·사운드 설치의 사실 관계를 구분한다.
3. 관객의 실제 행위와 작품의 추론적 효과를 분리한다.
4. 문장별 변경의 이유를 기록한다. 원본을 덮어쓰지 않고 별도 파일 또는 diff로 제안한다.
5. 젠더 중립적 영문 표기를 유지하며 생략한 사실을 만들어 내지 않는다.
